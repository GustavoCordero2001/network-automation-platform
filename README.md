# Network Automation Platform for Cisco Networks

Proyecto profesional de automatización de redes Cisco desarrollado como portafolio de Ingeniería en Telecomunicaciones.

## Objetivo

Desarrollar una plataforma capaz de administrar dispositivos Cisco mediante Python, Netmiko, Flask y Ansible.

## Tecnologías

* Python
* Cisco IOS
* Netmiko
* Flask
* SQLite
* Ansible
* Git
* GitHub
